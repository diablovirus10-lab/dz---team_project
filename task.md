## 🛠 ЭТАП 1: Настройка базовых модулей

### 1.1. Настройка логирования
- **Файл:** `src/utils/logger.py`
- **Описание:** Создать систему логирования для отладки и мониторинга
- **Что нужно реализовать:**
  - Функцию `get_logger(name)` — создание логгера с именем
  - Настройку формата: `[%(asctime)s] [%(levelname)s] [%(name)s] %(message)s`
  - Вывод в консоль (`ConsoleHandler`) и в файл `logs/bot.log` (`FileHandler`)

### 1.2. Валидаторы данных
- **Файл:** `src/utils/validators.py`
- **Описание:** Функции для проверки корректности данных
- **Что нужно реализовать:**
  - `validate_age(age)` — проверка возраста (14-100 лет)
  - `validate_city(city)` — проверка названия города (не пустое)
  - `validate_vk_id(vk_id)` — проверка VK ID (положительное число)
  - `validate_sex(sex)` — проверка пола (1 или 2)

### 1.3. Вспомогательные функции
- **Файл:** `src/utils/helpers.py`
- **Описание:** Общие утилиты для всего проекта
- **Что нужно реализовать:**
  - `format_age(age)` — форматирование возраста ("25 лет", "24 года")
  - `get_profile_link(vk_id)` — создание ссылки на профиль VK
  - `truncate_text(text, length)` — обрезка текста
  - `safe_int(value)` — безопасное преобразование в int

## 🌐 ЭТАП 2: VK API клиент

### 2.1. Обработка исключений VK API
- **Файл:** `src/vk_api/exceptions.py`
- **Описание:** Кастомные исключения для работы с VK API
- **Что нужно создать:**
  - `VKAPIError` (базовое)
  - `VKAuthError` (ошибка авторизации)
  - `VKRateLimitError` (превышен лимит запросов)
  - `VKUserNotFoundError` (пользователь не найден)

### 2.2. Утилиты VK API
- **Файл:** `src/vk_api/api_utils.py`
- **Описание:** Вспомогательные функции для работы с VK API
- **Что нужно реализовать:**
  - `handle_vk_error(error)` — обработка ошибок VK API
  - `retry_on_rate_limit(func)` — декоратор для повторных запросов при лимитах
  - `parse_vk_user(user_data)` — парсинг данных пользователя из ответа VK API
  - `calculate_age(bdate)` — вычисление возраста из даты рождения (формат "DD.MM.YYYY")

### 2.3. VK API клиент
- **Файл:** `src/vk_api/vk_client.py`
- **Описание:** Основной класс для работы с VK API
- **Методы:**
  - `__init__()` — инициализация клиента (загрузка токена, авторизация)
  - `get_user_profile(vk_id)` — получение профиля (`users.get`)
  - `search_users(sex, age_from, age_to, city, offset=0, count=20)` — поиск людей (`users.search`)
  - `get_user_photos(vk_id, count=10)` — получение фотографий (`photos.getAll`)
  - `get_user_interests(vk_id)` — получение интересов (парсинг музыки, групп)
  - `get_common_friends(user_vk_id, candidate_vk_id)` — общие друзья (`friends.getMutual`)

## 👤 ЭТАП 3: Регистрация и интерфейс бота

### 3.1. Форматирование сообщений
- **Файл:** `src/bot/message_formatter.py`
- **Описание:** Создание текстовых сообщений для бота
- **Что нужно реализовать:**

  - `format_candidate_card(candidate, photos, common_interests)` — карточка кандидата
  - `format_favorites_list(favorites)` — список избранных
  - `format_blacklist_list(blacklist)` — черный список
  - `format_settings(weights)` — текущие настройки поиска
  - `format_no_candidates()` — сообщение когда кандидаты закончились

### 3.2. Клавиатуры

  - `get_settings_keyboard()` — настройки поиска (inline)
  - `get_weight_adjustment_keyboard(criterion)` — изменение веса критерия

### 3.3. Менеджер состояний
- **Файл:** `src/bot/state_manager.py`
- **Описание:** Управление состояниями диалога с пользователем
- **Что нужно реализовать:**
  - Класс `StateManager` с методами: `get_state`, `set_state`, `clear_state`, `get_user_data`, `set_user_data`
  - Константы состояний: `STATE_MAIN_MENU`, `STATE_SEARCHING`, `STATE_SETTINGS` и т.д.

### 3.4. Инициализация пользователя в БД
- **Файл:** `src/database/db_manager.py`
- **Описание:** Дополнение существующего менеджера БД
- **Что нужно добавить:**

  - `update_user_profile(vk_id, **kwargs)` — обновление профиля

### 4.2. Сохранение кандидатов из VK
- **Файл:** `src/database/db_manager.py`
- **Описание:** Методы для сохранения данных из VK API
- **Что нужно добавить:**
  - `save_candidate_with_interests(candidate_data, interests)` — сохранение кандидата с интересами (в транзакции)
  - `save_candidate_photos(candidate_id, photos)` — сохранение фото (определение аватара, лайков)

### 4.3. Основная логика бота
- **Файл:** `src/bot/bot_logic.py`
- **Описание:** Обработчики команд и событий VK Bot API
- **Обработчики:**
  - `handle_start` — команда `/start`, регистрация, приветствие
  - `handle_find_pair` — поиск пары, показ карточки
  - `handle_like` — добавление в избранное, переход к следующему
  - `handle_dislike` — добавление в черный список, переход к следующему
  - `handle_skip` — отметка как просмотренного, переход к следующему
  - `handle_favorites` — просмотр и управление избранным
  - `handle_blacklist` — просмотр и управление черным списком
  - `handle_settings` — изменение весов критериев
  - `handle_callback` — обработка нажатий на inline кнопки

### 4.4. Загрузка и отправка фото
- **Файл:** `src/vk_api/api_utils.py` или `src/vk_api/vk_client.py`
- **Описание:** Методы для работы с загрузкой фото в VK
- **Что нужно добавить:**
  - `download_photo_from_url(url)` — скачивание фото по URL во временный файл
  - `upload_photo_to_vk(peer_id, photo_path)` — загрузка фото через VkUpload
  - `send_photo_with_message(peer_id, photo_url, text, keyboard)` — отправка фото с текстом
