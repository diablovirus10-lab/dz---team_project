# Инструкция по запуску интеграционных тестов БД

## Требования

Для запуска интеграционных тестов необходим работающий PostgreSQL сервер.

### Вариант 1: Использование Docker (рекомендуется)

```bash
# Запустить PostgreSQL контейнер
docker run -d --name vk-bot-postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=vk_bot_test \
  -p 5432:5432 \
  postgres:15-alpine

# Дождаться готовности (3-5 секунд)
sleep 5

# Запустить интеграционные тесты
pytest tests/integration/test_database_integration.py -v

# Остановить контейнер после тестов
docker stop vk-bot-postgres && docker rm vk-bot-postgres
```

### Вариант 2: Локальный PostgreSQL

1. Установите PostgreSQL 12+
2. Создайте базу данных:
```bash
createdb -U postgres vk_bot_test
```

3. Запустите тесты:
```bash
pytest tests/integration/test_database_integration.py -v
```

## Конфигурация

Тесты используют следующие параметры подключения:
- Host: localhost
- Port: 5432
- Database: vk_bot_test
- User: postgres
- Password: postgres

Для изменения параметров отредактируйте фикстуру `db_config` в файле `tests/integration/test_database_integration.py`.

## Что тестируется

Интеграционные тесты проверяют:

1. **Создание таблиц** - все 10 таблиц создаются корректно
2. **CRUD операции** - создание, чтение, обновление пользователей
3. **Управление диалогами** - создание, получение, закрытие
4. **История сообщений** - добавление и получение сообщений
5. **FSM состояния** - установка, получение, очистка состояний
6. **Отслеживание команд** - регистрация и логирование команд
7. **Намерения** - создание и логирование намерений
8. **Транзакции** - откат при ошибках
9. **Целостность данных** - уникальность, внешние ключи
10. **Логирование API** - запись и чтение логов запросов
11. **Пул соединений** - параллельные запросы
12. **Очистка БД** - полное удаление данных

## Маркеры pytest

Для запуска только интеграционных тестов:
```bash
pytest -m integration -v
```

Для исключения интеграционных тестов (быстрый прогон):
```bash
pytest -m "not integration" -v
```
